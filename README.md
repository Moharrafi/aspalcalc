AspalCalc - Sales & Analysis System

Aplikasi pencatatan penjualan aspal (Bitumax, Hijau, Hitam) yang terintegrasi dengan database MySQL.

Fitur:
- Kalkulator harga otomatis
- Analisis grafik penjualan harian dan bulanan
- Laporan cetak (Print Report)
- Bisa diinstal di HP (PWA)
- Notifikasi berhasil/gagal
- Keamanan data dengan MySQL online

Cara Menjalankan:
1. Copy file .env.example ke .env dan isi data MySQL
2. Jalankan: pnpm install
3. Jalankan init database: node scratch/init_db.js
4. Jalankan aplikasi: pnpm run dev
